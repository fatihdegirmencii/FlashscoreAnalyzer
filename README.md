# Flashscore Analyzer EXE

Bu proje, Windows için Python gerektirmeyen `FlashscoreAnalyzer.exe` üretir.

## En kolay yöntem

GitHub Actions iş akışını çalıştır. Ayrıntılı adımlar `KULLANIM.txt` dosyasındadır.

## Yerel derleme

Bilgisayarda Python 3.12 kuruluysa `EXE_OLUSTUR.bat` dosyasını çalıştır.

Üretilen dosya:

```text
dist\FlashscoreAnalyzer.exe
```

## Çalışma şartı

Son kullanıcı bilgisayarında Google Chrome kurulu olmalıdır. Selenium Manager uygun sürücüyü otomatik yönetir.
